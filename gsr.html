Definitions

formulas

Every number on this page, written against the column names in the panel spreadsheet. Fields shown in code are columns in the sheet. Anything marked calculated is derived by this dashboard rather than read straight from a column, and the derivation is spelled out.

Shared terms

Panel calculated
Every row in the sheet that has a numeric Age. Rows with a blank or non-numeric age are dropped before anything else runs, so they never reach a chart.
Age band calculated
Derived from Age:
18 and under = Age <= 18 19-64 = Age > 18 AND Age < 65 65+ = Age >= 65
Risk score sheet column
Read directly from the Risk column. It is the count of the nine diagnosis columns that hold a code for that patient:
Risk = COUNTA(Diabetes, SUD, Pain, Personality, Hypertension, Heart, COPD, Depression, Asthma)
A patient with hypertension and depression scores 2. Note that this weights every code group equally, so a substance use code counts the same as a diabetes code.
Chronic disease code calculated
Used by the age-band average and the time-since-last-visit split. It counts only the five medical chronic disease columns, not the behavioural health ones:
chronic disease = COUNTA(Diabetes, Hypertension, Heart, COPD, Asthma) > 0
Overall Diagnosis sheet column
Read directly from the Overall Diagnosis column, which holds either Chronic or Healthy. This is a wider definition than the chronic disease code above, because it counts all nine diagnosis columns.
If a file is loaded without that column, the dashboard fills it in:
Overall Diagnosis = IF(Risk >= 1, "Chronic", "Healthy")
As-of date calculated
There is no report date in the sheet, so one is inferred from the data. The dashboard takes the most recent date found anywhere in Encounter dates and adds 14 days, on the assumption that an extract is pulled shortly after the last visit it contains.
as-of = MAX(all Encounter dates in the file) + 14 days
Months since last visit calculated
Encounter dates is a comma-separated list of MM-DD-YYYY dates. The latest one is taken as the patient's last visit, and the gap is expressed in average months of 30.44 days.
months since last visit = (as-of - MAX(Encounter dates)) / 30.44
A patient with no parseable date is excluded from any chart that buckets by this value.
The percentage shown beside every count calculated
Every count-based chart prints the patient count with its share underneath. The denominator is stated in each chart's definition below, because it is not always the whole panel. Charts whose value is already an average or already a percentage do not get a second percentage added.
The age band and risk score filters calculated
Where a chart has filters, they subset the rows before the chart's formula runs, and the percentage denominator shrinks with the selection. The risk score filter matches one exact value of Risk, from 0 through 8.

Provider Patient Summary

The four summary tiles
Patients in panel = COUNT(Patient #) Adults over 18 = COUNT(Patient # where Age > 18) Adults with 2+ risk codes= COUNT(Age > 18 AND Risk >= 2) / COUNT(Age > 18) * 100 Not seen in over 12 mo = COUNT(months since last visit > 12)
These four tiles ignore the per-chart filters and always describe the whole loaded file.

Patient Demographics

Patients by age band
bar = COUNT(Patient # where age band = this band) share = bar / COUNT(Patient #) * 100
Age in ten-year bands
Buckets are upper-bound inclusive, so a patient aged exactly 30 falls in 21-30.
bar = COUNT(Patient # where lower < Age <= upper) buckets 0-10, 11-20, 21-30, 31-40, 41-50, 51-60, 61-70, 71-80, 80+ share = bar / COUNT(Patient #) * 100
Risk score by age band calculated
A stacked column per age band. Each segment is a value of Risk, with 4 and above collapsed into one segment so the chart stays readable.
segment = COUNT(Patient # where age band = this band AND Risk = n) top segment uses Risk >= 4 share = segment / COUNT(Patient # in this age band) * 100
The percentage is the share of that age band, not of the panel, so each column's segments sum to 100%.
Chronic condition vs. healthy by age band
Uses the Overall Diagnosis column, so a patient with only a substance use, depression, pain or personality code still counts as Chronic here.
bar = COUNT(Patient # where age band = this band AND Overall Diagnosis = "Chronic" or "Healthy") share = bar / COUNT(Patient # in this age band) * 100
Avg. # of chronic conditions by age band calculated
A mean, so no percentage is shown. Counts only the five medical chronic disease columns, which is why it runs lower than the Risk column would.
per patient = COUNTA(Diabetes, Hypertension, Heart, COPD, Asthma) bar = AVERAGE(per patient) across all patients in the age band

Diagnosis

Diagnosis prevalence
One bar per diagnosis column. A patient carrying three codes appears in three bars, so the bars deliberately sum to more than the panel.
bar = COUNTA(this diagnosis column) across the filtered rows share = bar / COUNT(filtered Patient #) * 100
Most common overlapping diagnosis codes calculated
Not a column in the sheet. The dashboard takes all 36 possible pairs of the nine diagnosis columns, counts the patients holding both codes, drops empty pairs and shows the ten largest.
for each pair (A, B) of the nine diagnosis columns: bar = COUNT(Patient # where A is not blank AND B is not blank) share = bar / COUNT(filtered Patient #) * 100 rank by bar descending, keep the top 10
A patient with three codes contributes to three different pairs, so these bars overlap each other by design.
Depression diagnosis by age band
The bar is already a percentage, so no second percentage is added.
bar = COUNTA(Depression where age band = this band) / COUNT(Patient # in this age band) * 100
The note underneath counts patients aged 18 and under with a non-blank Depression value, and reports the youngest and oldest of them.
Comorbidity clusters worth flagging calculated
Four named combinations, chosen because each one stacks clinical and crisis risk. They are not columns in the sheet.
SUD + depression = SUD and Depression both not blank SUD + chronic pain = SUD and Pain both not blank SUD + depression + pain = all three not blank Chronic illness + depression= Depression not blank AND COUNTA(Diabetes, Hypertension, Heart, COPD, Asthma) > 0 share = bar / COUNT(filtered Patient #) * 100

Visits

Office visit frequency
bar = COUNT(Patient # where Visits = 1), (Visits = 2), (Visits >= 3) share = bar / COUNT(filtered Patient #) * 100
Visits is the total visit count in the sheet. It is not the number of dates listed in Encounter dates, which is truncated to the five most recent.
Visit frequency by average risk score calculated
A mean, so no percentage is shown.
bar = AVERAGE(Risk) across patients in each Visits bucket buckets: Visits = 1, Visits = 2, 3 <= Visits <= 5, Visits >= 6
The note underneath counts patients with Visits of 6 or more and averages their Risk.
Time since last visit
Two series, split on the chronic disease code definition above, which is the narrow five-column one rather than Overall Diagnosis.
bar = COUNT(Patient # where months since last visit falls in 0-6, 6-12, 12-18 or 18+ months) split by COUNTA(Diabetes, Hypertension, Heart, COPD, Asthma) > 0 share = bar / COUNT(patients in that same series) * 100
Each series is its own denominator, so the two colours can be compared directly even when one is much larger.
Patients seen only once
population = Patient # where Visits = 1 bar = COUNT(population in this age band, split on months since last visit > 12) share = bar / COUNT(population) * 100
The denominator is every once-only patient in the current selection, not the whole panel, so the six bars sum to 100%.
Patients seen once by risk score
The same once-only population as the chart above, cut by Risk instead of age. Only risk scores that actually occur in the file are drawn.
population = Patient # where Visits = 1 bar = COUNT(population where Risk = n) share = bar / COUNT(population) * 100
Diagnosis code by months since last visit calculated
Pick a diagnosis in the filter to see the contact pattern for the patients carrying it. With All diagnoses selected the chart shows every patient in the current selection.
population = Patient # where the chosen diagnosis column is not blank bar = COUNT(population where months since last visit falls in 0-3, 3-6, 6-12, 12-18, 18-24 or 24+ months) share = bar / COUNT(population) * 100
The note underneath compares the average Visits of that group against everyone else in the selection, and counts those past six months without a visit.
Most visits recorded
rows = SORT(all patients, Visits descending), first 30 Since last visit column = months since last visit, rounded Conditions column = the diagnosis columns that are not blank
This table is not filtered by the age band or risk score controls.

Patient Insights

How the observations are written calculated
On each data load the dashboard assembles the aggregate counts shown on this page, sends only those aggregates to Claude, and asks for observations that each cite a number and point at one chart. No patient rows leave the browser. If that call cannot be made, a built-in rules engine writes the same observations from threshold tests against the same aggregates.

Data stays in this browser. Nothing is uploaded when you load a file. If the AI narrative is generated, only the aggregate counts shown on this page are sent, never individual patient rows.

To refresh: export Grace's spreadsheet with the same column headers, then choose Load new data. Charts, tables, definitions and observations all recalculate.
